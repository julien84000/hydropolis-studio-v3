# Hydropolis Studio V11.34

## Ritmonio — Scheda tecnica

Ritmonio expose les documents techniques dans la barre supérieure de chaque fiche produit :
- « Scheda tecnica »
- « Istruzioni di montaggio »

Ces liens utilisent des URL officielles de type `/download/?code=...` qui ne portent pas d'extension `.pdf`. V11.34 les traite désormais explicitement comme des PDF officiels.

### Effets dans Hydropolis
- La fiche technique de la référence Ritmonio est récupérée avec la photo et les métadonnées fabricant.
- Le lien « Fiche technique ↗ » apparaît dans « Projet par pièce ».
- La case « Inclure la fiche technique » est disponible pour le dossier client.
- La notice de montage est également récupérée lorsqu'elle est présente.
- Les articles Ritmonio déjà enregistrés sans fiche sont rafraîchis automatiquement.
- La logique photo + pastille de finition existante reste inchangée.
