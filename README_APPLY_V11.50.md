## Couverture Resigres
- 7 familles de receveurs : configurateur dépendant.
- 6 plans vasque CF + 6 plans vasque SF : configurateur dépendant.
- 4 familles de meubles : configurateur dépendant.
- Choix filtrés par modèle : type/forme → dimensions → matière → coloris → options.
- Options comprises et suppléments payants sélectionnables.
- Palier tarifaire supérieur pour les dimensions intermédiaires sur les matrices certifiées.

Les cellules tarifaires dont l'extraction du PDF n'est pas assez sûre restent en saisie manuelle de sécurité, mais la compatibilité produit/dimensions/matières/couleurs est gérée par le configurateur.
