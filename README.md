# Hydropolis Studio V5.3

## Dossier client plus éditorial et fluide

La présentation client a été repensée pour être moins rigide et plus proche d'un
book d'architecture intérieure / catalogue haut de gamme.

### Aperçu interactif
- couverture asymétrique avec image plein cadre et cartouche flottant ;
- produits disposés avec un léger décalage vertical pour casser l'effet de grille stricte ;
- typographie plus éditoriale ;
- fonds très légers et espaces plus généreux ;
- survol subtil des produits ;
- effet parallax au défilement de l'aperçu.

### PDF
Les effets interactifs sont automatiquement désactivés à l'impression :
le PDF reste A4 paysage, propre, stable et sans déformation.

Les options prix/références et les pages techniques restent compatibles.
