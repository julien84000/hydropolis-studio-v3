# Hydropolis Studio V11.49 — Resigres

## Installation
1. Uploader le contenu du ZIP à la racine du dépôt GitHub en conservant les dossiers.
2. Render — Build Command :
   `node apply-v11.49-consolidated.js`
3. Start Command :
   `npm start`
4. Deploy latest commit.
5. Après le premier déploiement, rechargement forcé du navigateur (Cmd/Ctrl + Shift + R).

## Principales corrections
- Resolver photos Resigres 11.49 : pages produit + fallback direct sur les images des pages catégories.
- Invalidation des anciennes photos Resigres mises en cache avant 11.49.
- Receveurs certifiés : dimensions réelles avec tarification au palier supérieur pour les grilles intermédiaires.
- Selene : 6 formes illustrées, matière, coloris, 1 / 1 XL / 2 vasques, dimensions, options comprises et suppléments payants.
