# Hydropolis Studio V11.17

## Recor — choix visuel des pieds
- Intégration des 8 visuels fournis pour Aster, Ball & Claw, bois, Imperial, Lion, Princess, Carlton et Pedestal.
- Les variantes de finition d’un même modèle réutilisent le visuel de forme correspondant.
- Le configurateur obligatoire Recor affiche désormais une vignette pour chaque jeu de pieds compatible.
- Le projet par pièce affiche aussi ces vignettes dans le bloc de choix Recor.
- Le pied sélectionné conserve son visuel dans le dossier client. Les photos sont marquées comme visuels de forme : la finition photographiée peut différer de la finition choisie.
- Le visuel Pedestal est utilisé comme illustration générique des socles Recor avec avertissement non contractuel.
- Les 8 images sont incluses dans le cache hors connexion.

## Correctif associé
- Correction d’une variable de modèle manquante dans le bloc Recor du projet par pièce.
