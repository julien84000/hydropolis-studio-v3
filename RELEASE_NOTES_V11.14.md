# Hydropolis Studio V11.14 — Release notes

## Évolution d’interface

V11.14 prolonge V11.13 sans réécrire le cœur métier. La nouvelle couche d’expérience reprend le langage visuel défini pour Hydropolis Studio : navigation latérale sombre, grands espaces, cartes visuelles, recherche centrale et interactions courtes, avec une ergonomie inspirée des principes d’Apple et de Canva sans copier leurs interfaces.

- nouvel accueil / dashboard visuel ;
- raccourcis vers les univers Robinetterie, Baignoires, Douches et Accessoires ;
- recherche depuis l’accueil vers le moteur multi-sources ;
- inspirations dynamiques construites à partir du catalogue réellement chargé ;
- produit mis en avant avec ajout direct au projet ;
- favoris persistants par utilisateur ;
- vue Comparateur dédiée jusqu’à quatre produits ;
- hub Exports pour PDF, Excel et moodboard ;
- navigation réorganisée : Accueil, Catalogue, Mes projets, Favoris, Comparateur, Exports, Projet par pièce, Marge & devis, Présentation client ;
- design plus compact, vitré et éditorial, avec couleurs Hydropolis et accents laiton.

## Fonctions conservées

Toutes les briques V11.13 restent présentes : recherche fédérée, alternatives intelligentes, cache hors connexion, exports enrichis, corrections de sauvegarde/sessions, Hotbath Drawing, Sanitairkamer, Recor avec pieds obligatoires, Zucchetti PDF page 3, projets/pièces, devis/remises/marges, dossier client A4 et PostgreSQL/Supabase.

## Fabricants

Les 7 fabricants réellement intégrés restent : Amphora, Catalano, Coalbrook, Hotbath, Lefroy Brooks, Recor et Zucchetti. Aucune nouvelle marque n’est déclarée sans données vérifiées.

## Validation

Les contrôles exécutés lors de la génération sont consignés dans `BUILD_INFO.json`.
