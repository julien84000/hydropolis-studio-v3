# Hydropolis Studio V11.33

## Recor — Projet par pièce

- Une configuration Recor validée n'affiche plus toute la liste des pieds et vidages compatibles sous la baignoire.
- Le bloc devient un résumé compact « Configuration Recor ✓ » avec uniquement :
  - les pieds sélectionnés ;
  - le ou les vidages sélectionnés, ou « Aucun vidage sélectionné ».
- Les pieds et vidages liés à la baignoire ne sont plus rendus comme articles autonomes dans « Projet par pièce ».
- Les accessoires restent présents dans l'état du projet : prix, coût d'achat, marge, devis et dossier client sont donc inchangés.
- Le bouton « Modifier la configuration » rouvre le configurateur Recor avec les choix existants présélectionnés.
- Lors de la modification, seuls les accessoires liés sont remplacés ; la baignoire n'est pas dupliquée.

Aucune règle tarifaire, aucun port fournisseur Recor et aucun comportement du dossier client n'est modifié.
