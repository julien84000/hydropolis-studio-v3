# Hydropolis Studio V11.46

## Resigres 2026 — tarification intégrée

- Cosmo, Vento, Urban et Nix : grilles 2026 certifiées intégrées pour les finitions lisibles.
- Extraplano Contract, Vento Contract, Cosmo Contract et Nix Contract : calcul automatique au m².
- Minimum de facturation 0,5 m² appliqué aux règles Contract concernées.
- RAL/NCS (+95 €) et rainure de paroi (+0,55 €/cm) calculés automatiquement pour les familles concernées.
- Cosmo Contract Solid Surface : 992 €/m² ; Lisa : 845 €/m².
- Vento Contract et Nix Contract Lisa : 845 €/m².
- Extraplano Contract : Lisa 800 €/m² ; Solid Surface 970 €/m².
- Quelques tarifs simples supplémentaires sont intégrés : baignoires Nalu/Delia et miroirs standards RD/SQ/FS/FL.

## Sécurité tarifaire

Les rares cellules dont le glyphe de prix est endommagé dans le PDF sont volontairement laissées non automatiques. Le configurateur demande alors uniquement le prix de cette cellule, au lieu d'inventer une valeur.

## Déploiement

Build command Render : `node apply-v11.46-consolidated.js`

Start command : `npm start`
