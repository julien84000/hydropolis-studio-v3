# Hydropolis Studio V11.40

## Recherche d’image automatique pour tous les articles

- Tout article catalogue ajouté à un projet lance immédiatement sa recherche d’image fabricant en arrière-plan.
- La règle couvre les dix fabricants, toutes les catégories, les accessoires et les éléments créés par les configurateurs.
- Une file limitée à trois recherches simultanées garde l’ajout au projet fluide, même lors d’un ajout groupé.
- Les correspondances déjà vérifiées sont réutilisées depuis le cache ; Catalano, les baignoires Recor, Gessi et Ritmonio conservent leur rafraîchissement renforcé pour les galeries, finitions ou documents associés.
- En cas d’indisponibilité temporaire du fournisseur, l’article reste dans le projet avec son visuel catalogue et la relance manuelle demeure disponible.
